# TUI Studio - Terminal UI Builder

A free, open-source tool for building Terminal User Interfaces (TUIs) with visual components and styling.

## Features

- **Drag-and-drop UI Builder** - Visually design terminal UI components
- **Body & Style Configuration** - Create structured terminal layouts with custom styling
- **Terminal Integration** - Works seamlessly with Termux and terminal environments
- **Code Export** - Generate code for your terminal applications
- **Component Library** - Pre-built terminal components (buttons, inputs, panels, tables, etc.)

## Getting Started

### Requirements
- Node.js or Go (depending on implementation)
- Terminal/Termux environment
- Git

### Installation

```bash
git clone https://github.com/jomjmc/jomjmc0495.git
cd jomjmc0495
npm install  # or appropriate setup command
```

## Usage

1. **Design Your UI** - Use the builder interface
2. **Configure Body** - Set terminal dimensions and layout
3. **Apply Styles** - Customize colors, borders, spacing
4. **Export** - Generate code for your Termux terminal apps
5. **Integrate** - Use generated code in your terminal tools
